Bilgisayardaki tüm Claude Code oturumlarını tek ekranda gösteren panel. Claude Code kurulu ve giriş yapılmış olmalı; panel ayrıca hesap istemez.

## Mac'e kurulum

1. Terminal'de `uname -m` yaz: `arm64` ise **ClaudePanel-0.10.1-osx-arm64.zip** (Apple Silicon, M1–M5), `x86_64` ise **osx-x64** (Intel).
2. Zip'i indir, çift tıklayıp aç (İndirilenler'de `ClaudePanel-osx-arm64` klasörü çıkar).
3. Terminal'de:

```
cd ~/Downloads/ClaudePanel-osx-arm64
xattr -dr com.apple.quarantine .
chmod +x ClaudePanel
codesign --force --sign - ClaudePanel
codesign --force --sign - runtimes/*/*.dylib
./ClaudePanel
```

Panel kendi penceresinde açılır (Chrome, Edge, Brave ya da Chromium; yoksa varsayılan tarayıcı). Denenecekler listesi zip içindeki `MAC_TEST.md`'de.

## Windows'a kurulum

**ClaudePanel-0.10.1-win-x64.zip**'i aç, `ClaudePanel.exe`'yi çalıştır. Gereken: Windows 10/11, [.NET 10 çalışma zamanı](https://dotnet.microsoft.com/download/dotnet/10.0) (ASP.NET Core Runtime), Edge veya Chrome.

İndirilen dosyayı doğrulamak için: `SHA256SUMS` (Windows: `Get-FileHash <zip>`, Mac: `shasum -a 256 <zip>`).

## Bu sürümde

- **Kota panelin içinde:** kota halkaları için statusline betiği gerekmez; panel kotayı kendisi okur (Mac'te Anahtar Zinciri'nden).
- **Kota koruması:** panelin başlattığı oturumlarda 5 saatlik kotadan %5 kalınca yalnız okuma ve hafıza kaydı yapılır, ekstra ücretli kullanıma kayılmaz.
- **Ayarlar → Terminal oturumlarında kota** (varsayılan kapalı): terminaldeki Claude Code'un altında plan, kota ve bağlam satırı + aynı koruma. Mevcut durum satırınız yedeklenir, kapatınca geri gelir.
- Windows exe'si uygulama simgesini taşıyor.
