Bilgisayardaki tüm Claude Code oturumlarını tek ekranda gösteren panel. Claude Code kurulu ve giriş yapılmış olmalı; panel ayrıca hesap istemez.

## Mac'e kurulum

1. Terminal'de `uname -m` yaz: `arm64` ise **ClaudePanel-0.17.0-osx-arm64.zip** (Apple Silicon, M1–M5), `x86_64` ise **osx-x64** (Intel).
2. Zip'i indir, çift tıklayıp aç (İndirilenler'de `ClaudePanel-osx-arm64` klasörü çıkar).
3. Terminal'de:

```
cd ~/Downloads/ClaudePanel-osx-arm64
xattr -dr com.apple.quarantine .
chmod +x ClaudePanel
codesign --force --sign - ClaudePanel
codesign --force --sign - runtimes/*/*.dylib
./ClaudePanel
```

Panel kendi penceresinde açılır (Chrome, Edge, Brave ya da Chromium; yoksa varsayılan tarayıcı). Denenecekler listesi zip içindeki `MAC_TEST.md`'de.

## Windows'a kurulum

**ClaudePanel-0.17.0-win-x64.zip**'i aç, `ClaudePanel.exe`'yi çalıştır. Gereken: Windows 10/11, [.NET 10 çalışma zamanı](https://dotnet.microsoft.com/download/dotnet/10.0) (ASP.NET Core Runtime), Edge veya Chrome.

İndirilen dosyayı doğrulamak için: `SHA256SUMS` (Windows: `Get-FileHash <zip>`, Mac: `shasum -a 256 <zip>`).

- **Zamanlanmış işler:** Windows sonuç kodları Türkçe açıklanır ("zaten çalışıyordu", "kapanışta durduruldu" hata sayılmaz). Bir görevin bilerek döndürdüğü kod "bu görev için normal" diye işaretlenebilir. Satırdan **Şimdi çalıştır**, **Logu aç**, **Claude'a incelet**.
- **Gece koruması** daha çok yazma komutunu yakalar (`gh api -f`, `--method=POST`, curl/wget veri gönderme, ssh/scp, betik içinden HTTP yazma). Koruma dosyası okunamazsa artık engeller. Bu bir "en iyi çaba" önlemidir; asıl koruma Claude Code izin ayarlarıdır.
- **Yeni oturum görev metninden önce `--`:** `-` ile başlayan ya da komut adı olan metin seçenek sanılmaz.
- **Dikte modeli SHA256 ile doğrulanır;** uyuşmayan dosya kullanılmaz.
- **Oturum kartı:** soru ya da izin bekleyen oturum "Bekleyenler"de ("cevap bekliyor"). Oturumun nerede açık olduğu yazar (Masaüstü uygulaması / VS Code / Terminal); masaüstü uygulamasındaki oturumda düğme "Uygulamaya git". Birden çok sanal masaüstü varsa masaüstü numarası ya da adı. Windows Terminal'de "Sekmeye git" doğru sekmeyi kimliğiyle bulur.
