Bilgisayardaki tüm Claude Code oturumlarını tek ekranda gösteren panel. Claude Code kurulu ve giriş yapılmış olmalı; panel ayrıca hesap istemez.

## Mac'e kurulum

1. Terminal'de `uname -m` yaz: `arm64` ise **ClaudePanel-0.12.0-osx-arm64.zip** (Apple Silicon, M1–M5), `x86_64` ise **osx-x64** (Intel).
2. Zip'i indir, çift tıklayıp aç (İndirilenler'de `ClaudePanel-osx-arm64` klasörü çıkar).
3. Terminal'de:

```
cd ~/Downloads/ClaudePanel-osx-arm64
xattr -dr com.apple.quarantine .
chmod +x ClaudePanel
codesign --force --sign - ClaudePanel
codesign --force --sign - runtimes/*/*.dylib
./ClaudePanel
```

Panel kendi penceresinde açılır (Chrome, Edge, Brave ya da Chromium; yoksa varsayılan tarayıcı). Denenecekler listesi zip içindeki `MAC_TEST.md`'de.

## Windows'a kurulum

**ClaudePanel-0.12.0-win-x64.zip**'i aç, `ClaudePanel.exe`'yi çalıştır. Gereken: Windows 10/11, [.NET 10 çalışma zamanı](https://dotnet.microsoft.com/download/dotnet/10.0) (ASP.NET Core Runtime), Edge veya Chrome.

İndirilen dosyayı doğrulamak için: `SHA256SUMS` (Windows: `Get-FileHash <zip>`, Mac: `shasum -a 256 <zip>`).

## Bu sürümde

- **Takip'te depo başına tek düğme:** depo durumuna göre "Commit et", "Gönder" ya da "Commit et ve gönder". Git bölümünün başında "Tümünü commit et ve gönder" var.
- **Gönder artık oturum açmıyor:** panel `git push`u kendisi yapar, kota harcamaz. Göndermeden önce commit'ler denetlenir; izin dosyası, `.env`, anahtar dosyası ya da belirteç/parola kalıbı bulunursa gönderim yapılmaz ve satırda nedeni yazar (bulunan değer hiçbir yere yazılmaz).
- **Commit et arka planda:** oturum listesinde kart açmadan çalışır; karar gerekirse oturum görünür olur ve satırda "Kararın gerekiyor" çıkar.
- **Aynı projede ikinci oturum açılmıyor:** projede oturum varken yeni oturum istenirse pencere seçenek sunar: mevcut oturuma gönder, iş bitince gönder, ayrı çalışma kopyasında aç (git worktree) ya da yine de aç. Kartta "Bu projede N oturum açık" rozeti, Takip'te "Çakışma riski" bölümü var.
- **Takip bölümleri açılır-kapanır**, durum hatırlanır; oturumu açık olan projeler Git ve Sıradaki işler listelerinde gizlenir.
