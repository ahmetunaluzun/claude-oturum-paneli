Bilgisayardaki tüm Claude Code oturumlarını tek ekranda gösteren panel. Claude Code kurulu ve giriş yapılmış olmalı; panel ayrıca hesap istemez.

## Mac'e kurulum

1. Terminal'de `uname -m` yaz: `arm64` ise **ClaudePanel-0.15.1-osx-arm64.zip** (Apple Silicon, M1–M5), `x86_64` ise **osx-x64** (Intel).
2. Zip'i indir, çift tıklayıp aç (İndirilenler'de `ClaudePanel-osx-arm64` klasörü çıkar).
3. Terminal'de:

```
cd ~/Downloads/ClaudePanel-osx-arm64
xattr -dr com.apple.quarantine .
chmod +x ClaudePanel
codesign --force --sign - ClaudePanel
codesign --force --sign - runtimes/*/*.dylib
./ClaudePanel
```

Panel kendi penceresinde açılır (Chrome, Edge, Brave ya da Chromium; yoksa varsayılan tarayıcı). Denenecekler listesi zip içindeki `MAC_TEST.md`'de.

## Windows'a kurulum

**ClaudePanel-0.15.1-win-x64.zip**'i aç, `ClaudePanel.exe`'yi çalıştır. Gereken: Windows 10/11, [.NET 10 çalışma zamanı](https://dotnet.microsoft.com/download/dotnet/10.0) (ASP.NET Core Runtime), Edge veya Chrome.

İndirilen dosyayı doğrulamak için: `SHA256SUMS` (Windows: `Get-FileHash <zip>`, Mac: `shasum -a 256 <zip>`).

- **Drive'a yüklenecekler yalnız en güncel sürümü gösterir:** kütükte aynı belgenin birden çok sürümü açık duruyorsa (aynı kılavuzun 1.2.0, 1.2.1, 1.3.0 klasörleri gibi) listede yalnız en yüksek sürüm kalır, eskiler yüklendi sayılır.
