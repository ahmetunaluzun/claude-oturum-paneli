Bilgisayardaki tüm Claude Code oturumlarını tek ekranda gösteren panel. Claude Code kurulu ve giriş yapılmış olmalı; panel ayrıca hesap istemez.

## Mac'e kurulum

1. Terminal'de `uname -m` yaz: `arm64` ise **ClaudePanel-0.15.0-osx-arm64.zip** (Apple Silicon, M1–M5), `x86_64` ise **osx-x64** (Intel).
2. Zip'i indir, çift tıklayıp aç (İndirilenler'de `ClaudePanel-osx-arm64` klasörü çıkar).
3. Terminal'de:

```
cd ~/Downloads/ClaudePanel-osx-arm64
xattr -dr com.apple.quarantine .
chmod +x ClaudePanel
codesign --force --sign - ClaudePanel
codesign --force --sign - runtimes/*/*.dylib
./ClaudePanel
```

Panel kendi penceresinde açılır (Chrome, Edge, Brave ya da Chromium; yoksa varsayılan tarayıcı). Denenecekler listesi zip içindeki `MAC_TEST.md`'de.

## Windows'a kurulum

**ClaudePanel-0.15.0-win-x64.zip**'i aç, `ClaudePanel.exe`'yi çalıştır. Gereken: Windows 10/11, [.NET 10 çalışma zamanı](https://dotnet.microsoft.com/download/dotnet/10.0) (ASP.NET Core Runtime), Edge veya Chrome.

İndirilen dosyayı doğrulamak için: `SHA256SUMS` (Windows: `Get-FileHash <zip>`, Mac: `shasum -a 256 <zip>`).

## Bu sürümde

- **Claude Code'u panel günceller:** Takip'teki güncelleme denetimi Claude Code'un yeni sürümünü görünce panel `claude update`'i arka planda kendisi çalıştırır. Satırda "Güncelleniyor…", bitince "Claude Code X kuruldu, yeni oturumlarda geçerli"; olmazsa hatanın kendisi yazar. Her sürüm için bir kez denenir, başarısızsa 6 saat sonra yeniden.
- **"Şimdi güncelle" düğmesi:** güncellemeyi beklemeden başlatır.
- Açık oturumlar başladıkları sürümle sürer; yeni sürüm yeni açılan oturumlarda geçerli olur. Panelin kendi yeni sürümü yine yalnız bildirilir (sürüm sayfası bağlantısı).
