Bilgisayardaki tüm Claude Code oturumlarını tek ekranda gösteren panel. Claude Code kurulu ve giriş yapılmış olmalı; panel ayrıca hesap istemez.

## Mac'e kurulum

1. Terminal'de `uname -m` yaz: `arm64` ise **ClaudePanel-0.13.0-osx-arm64.zip** (Apple Silicon, M1–M5), `x86_64` ise **osx-x64** (Intel).
2. Zip'i indir, çift tıklayıp aç (İndirilenler'de `ClaudePanel-osx-arm64` klasörü çıkar).
3. Terminal'de:

```
cd ~/Downloads/ClaudePanel-osx-arm64
xattr -dr com.apple.quarantine .
chmod +x ClaudePanel
codesign --force --sign - ClaudePanel
codesign --force --sign - runtimes/*/*.dylib
./ClaudePanel
```

Panel kendi penceresinde açılır (Chrome, Edge, Brave ya da Chromium; yoksa varsayılan tarayıcı). Denenecekler listesi zip içindeki `MAC_TEST.md`'de.

## Windows'a kurulum

**ClaudePanel-0.13.0-win-x64.zip**'i aç, `ClaudePanel.exe`'yi çalıştır. Gereken: Windows 10/11, [.NET 10 çalışma zamanı](https://dotnet.microsoft.com/download/dotnet/10.0) (ASP.NET Core Runtime), Edge veya Chrome.

İndirilen dosyayı doğrulamak için: `SHA256SUMS` (Windows: `Get-FileHash <zip>`, Mac: `shasum -a 256 <zip>`).

## Bu sürümde

- **Takip'te Drive'a yüklenecekler:** projelerdeki `GUNCELLEME_KUTUGU.md` dosyalarının açık "Drive" bölümlerindeki dosyalar listelenir (dosya, sürüm, ne zamandır beklediği). "Yükledim" ile işaretlenir; dosya yeniden üretilirse satır geri gelir. "Kütüğü kapat" kütüğü bir arka plan oturumuyla günceller. Panel kütüğe kendisi yazmaz.
- **Projeye göre gruplama** (varsayılan) ya da türe göre görünüm; önemliler üstte.
- **Süzgeç çipleri:** Tümü / Git / Planlar / Drive / Kararlar, sayılarıyla.
- **Ertele (yarına) ve Gizle:** gizlenen öğe durumu değişince geri gelir; altta "N öğe gizli ya da ertelendi — göster".
- **"yeni" işareti:** son bakıştan sonra çıkan öğelerde.
- **Toplu işlemler:** üstte "Toplu" menüsü. Bölümler kapalıyken de "Tüm bekleyen depoları commit et ve gönder", ayrıca öğe seçip Commit et ve gönder / Ertele / Gizle / Yükledim.
